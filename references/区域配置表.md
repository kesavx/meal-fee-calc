## 字段说明（新增区域时按此填）

| 字段 | 含义 |
|---|---|
| 区域 | 区域名称，脚本 --region 参数与此一致 |
| 早餐餐标 | 早餐抵扣上限（元/次） |
| 午餐餐标 | 午餐标准价（元/次） |
| 晚餐餐标 | 晚餐标准价（元/次） |
| 默认班次 | 无班次表时的兜底上班-下班时间，格式 HH:MM-HH:MM |
| 早餐提前到岗线 | 白班提前到岗 ≥1h 的截止打卡时间 |
| 备注 | 该区域特殊规则，如中班工作餐、外租房等 |

## 新增区域检查清单

1. 本表加一行（区域名、餐标、默认班次、提前到岗线）；
2. `scripts/regions.csv` 加一行同名配置；
3. 如有区域特有规则（如中班工作餐），在「备注」写明，并在 `规则基准.md` 第八章特殊情况或新增章节补充；
4. 用该区域一份真实数据跑 `scripts/calc_meal_fee.py` 验证，结果与人工核对一致后交付。

## 区域特例备忘

- **广东中班（15:40-23:59）**：上班期间晚餐为工作餐免费（2022年请示，工程室）。如该区域中班员工晚餐被扣，需核实其班次后按工作餐处理。
