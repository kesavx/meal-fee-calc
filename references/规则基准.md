# 开餐餐费核算规则基准（通用版）

> 本文件是餐费核算的**规则本体**，所有区域共同遵守。区域差异见 `区域配置表.md`。
> 规则变更必须在本文件末尾「变更记录」追加，可追溯。

## 一、适用范围与数据来源

**全部北森考勤人员**。每笔餐补/免费判定需要**实际就餐（刷卡）+ 满足条件**，数据来源三件套：

| 条件 | 数据来源 | 作用 |
|---|---|---|
| ① 加班时间核实 | 加班记录表 | 以**生效加班时间**（实际打卡加班时间、实际打卡结束时间）判断达标、覆盖哪餐 |
| ② 班次/工作餐判定 | 班次表（或区域默认班次） | 判断刷卡是否落在班次工作时间内（工作餐免费） |
| ③ 食堂就餐记录 | 食堂刷卡明细 | 判断实际吃了哪餐、实际消费金额 |

> 核心口径：**真的刷卡吃了 + 属于工作餐或加班覆盖该餐 + 够时长**，才免费/抵扣；否则员工自付。

## 二、餐别时段定义

| 餐别 | 时段 |
|---|---|
| 早餐 | 05:30 - 09:00 |
| 午餐 | 10:30 - 14:30 |
| 晚餐 | 15:30 - 20:30 |

- 刷卡记录按刷卡时间落入上述时段分类；
- 加班时间与上述时段**有任意重叠（含边界时刻）**即判定覆盖该餐别。

## 三、工作餐定义（新增）

**员工在本班次工作时段内刷卡就餐的，视为工作餐，由公司全额承担，无需加班条件。**

- 例：中班 15:40-23:59，上班期间吃晚餐 → 工作餐免费；
- 例：白班 8:30-17:15，上班期间吃午餐 → 工作餐免费；
- 工作餐与加班餐补**不重复**：同一餐已按工作餐免费的，不再占用加班抵餐次数；
- **早餐不适用工作餐**：早餐一律按 5.4 判定（仅提前到岗、晚班跨天收工两种情况），上班后刷卡吃早餐不因"落在班次内"而免费；
- **班次边界取左闭右开**：刷卡时间须 ≥ 上班时刻且 **< 下班时刻**。下班时刻之后刷卡（如 17:15 下班、17:15:03 刷卡）不算班次内，按加班餐补判定；
- 无班次表时按区域默认班次（见区域配置表）判定；班次表为最高优先。

## 四、日常餐费标准

| 餐别 | 工作日 | 周末/节假日 |
|---|---|---|
| 早餐 | 按区域餐标（扬州2元/广东3元，外租房员工） | 按区域餐标 |
| 午餐 | **班次时长≥4小时：免费**；**<4小时：扣5元**（不含加班时间，见备注①） | 5元/次 |
| 晚餐 | 5元/次 | 5元/次 |

> 备注①（黄少君规则，2026-10 新增）：工作日午餐免费以当天实际班次工作时长≥4小时为前提（**不含加班**）。不足4小时的，午餐不豁免按5元扣费——即使当天刷卡金额为0（原本免单），也需倒扣5元。

## 五、加班餐补自动判定

### 5.1 判定时间基准
一律用加班单上的**生效加班时间**（实际打卡加班时间/实际打卡结束时间），不用申请时间。

### 5.2 时长门槛与可抵餐次

| 场景 | 加班时长 | 可抵餐次 |
|---|---|---|
| 工作日加班 | ≥1小时 | 1餐 |
| 周末/节假日加班 | 3～5小时（含5小时整） | 1餐 |
| 周末/节假日加班 | >5小时 | 2餐 |

> 5小时整属「3～5小时」档抵1餐；**超过**5小时才抵2餐。

### 5.3 餐别自动匹配

| 可抵餐别 | 自动判定条件 |
|---|---|
| 午餐 | 加班生效时间与午餐时段（10:30-14:30）有重叠（**仅周末判定**；工作日午餐本就免费/4小时规则） |
| 晚餐 | 加班生效时间与晚餐时段（15:30-20:30）有重叠 |
| 早餐 | 见 5.4 早餐特殊规则 |

### 5.4 早餐特殊规则

**早餐只有以下两种情况由公司承担：**

| 场景 | 判定标准 |
|---|---|
| 白班早上提前到岗加班 | 实际加班开始时间 ≤ 上班时间 - 1小时（按班次：8:30班次→≤07:30；9:00班次→≤08:00；晚班不适用） |
| 晚班后次日早上 | 晚班加班跨天，实际打卡结束时间 ≥ 次日05:30 |

> 其他情况早餐一律不补。

### 5.5 餐次分配（抵餐顺序固定）

1. 可抵餐次 = 时长档位给出的餐次数；
2. 从覆盖的餐别中按**晚餐 > 午餐 > 早餐**顺序抵扣；
3. 只覆盖一餐的，就抵覆盖的那一餐；
4. **不折现**：覆盖餐别不足餐次数时，多余餐次作废——不结转、不折现、不换钱；
5. 一天同餐只抵一笔；
6. **只在「加班覆盖 + 当天实际刷卡」的餐别中抵扣**：加班同时覆盖午晚餐、可抵 1 餐，但员工当天只吃了午餐（未吃晚餐）的，应抵午餐，不得把额度按"晚餐优先"作废；该条优先于第 2 条的顺序规则。

### 5.6 跨天加班归属

- 加班归属日期 = **实际打卡结束时间所在日期**；
- 时长门槛按**加班开始日期**判断（周日开工按周末门槛）。

## 六、抵扣金额

| 项目 | 扬州 | 广东 |
|---|---|---|
| 早餐抵扣上限 | 2元/次 | 3元/次 |
| 午餐抵扣 | 5元/次 | 5元/次 |
| 晚餐抵扣 | 5元/次 | 5元/次 |

**早餐按实际消费金额抵扣，不超过上限**（如广东实际消费3元→全抵；消费5元→抵3元自付2元）。

## 七、抵扣前提与限制

1. **必须实际就餐**：自动判定覆盖该餐但当天没刷卡，不补。
2. **必须够时长**：加班未达时长门槛，不产生可抵餐次。
3. **一天同餐只抵一笔**。
4. **优先抵晚餐**：晚餐 > 午餐 > 早餐。
5. **撤销记录排除**：加班记录「单据类型」=撤销不参与核算。
6. **重复记录去重**：同工号+同日期+同餐别重复刷卡只保留一笔。
7. **周末午餐必须加班达标才免费**：周末午餐只有加班且覆盖午餐时段才由公司承担，否则自付5元。
8. **工作日午餐4小时门槛**：班次时长<4小时（不含加班）不豁免午餐，扣5元。

## 八、特殊情况说明

| 情况 | 处理方式 |
|---|---|
| 调休上班日（如9/20周日） | 按**工作日**规则执行（午餐免费前提同工作日规则） |
| 刷卡金额为空 | 按标准餐标补录（区域餐标） |
| 加班达标但没刷卡 | 不补 |
| 刷卡但没加班/不达标 | 不补，员工自付 |
| 班次时间内就餐 | 工作餐，免费（不占加班抵餐次数） |

## 九、计算示例

**示例1：工作日正常吃午餐（班次≥4h）** → 免费，扣0元
**示例2：工作日加班1小时（16:30-17:30）吃晚餐** → 覆盖晚餐，抵5元，扣0元
**示例3：周末没加班吃午餐** → 扣5元
**示例4：周末加班4小时（12:00-16:00）吃午+晚** → 覆盖午+晚，可抵1餐→优先抵晚餐5元；午餐扣5元
**示例5：周末加班6小时（08:30-14:30）吃午+晚** → 覆盖午餐抵5元；晚餐未覆盖额度作废；晚餐扣5元
**示例6：白班07:00到岗加班后吃早餐** → 提前≥1h覆盖早餐，扬州实际消费2元全抵/3.5元抵2元自付1.5元
**示例7：晚班加班到次日06:00吃早餐** → 结束06:00≥05:30覆盖早餐，广东实际消费2.5元全抵/5元抵3元自付2元
**示例8：周日22:00加班到周一02:00（跨天）** → 归属周一；门槛按周日（周末）≥3h达标；未覆盖用餐时段；周一早餐因收工02:00未达05:30不补，自付餐标
**示例9：周日21:00加班到周一06:30** → 归属周一；门槛按周日达标；收工06:30≥05:30覆盖周一早餐；必须周一有早餐刷卡才成立
**示例10：晚班20:00-次日04:45（收工未达5:30）** → 不覆盖早餐，次日早餐自付
**示例11：工作日班次时长<4小时吃午餐（新规则）** → 午餐不豁免，扣5元
